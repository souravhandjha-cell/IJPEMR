IMPORTANT:
1. Upload all HTML/CSS files to the GitHub Pages repository root.
2. Keep the filenames unchanged.
3. The current submission page uses official email submission.
4. ISSN, DOI and indexing are deliberately marked as pending until officially obtained.
5. Editorial board names/affiliations should be published only after confirming consent and current affiliations.
